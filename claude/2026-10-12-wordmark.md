# 12 Oct 2026 — nav strip wordmark: FADE -> CHEWING THE CEILING

## What changed (all uncommitted)
- `frontend/src/components/Strip.jsx` — the `#lnv-brand` wordmark in the rail (zone 1) now reads CHEWING THE CEILING, all caps, same blue (`--pastel-blue-mid`), Barlow 900.
  - One vertical line (`writing-mode: vertical-rl`, rotated 180° so it reads bottom to top): CHEWING 84px, then THE CEILING 24px carrying on straight after the G. THE CEILING sits on CHEWING's baseline (`vertical-align: calc((var(--cw) - var(--cl)) * -0.35)`) so the bottoms of all the letters are flush.
  - Sizes come from the CSS vars `--cw` (CHEWING) and `--cl` (THE CEILING) and the position from `left`/`bottom`, applied in a `useEffect`. Defaults: `{ chewing: 84, ceiling: 24, left: 23, bottom: 6 }`. These were read off gabriel's screenshot, so they may be a few px off.
  - Same scroll-driven fade-in as FADE had: starts at opacity 0, `LayoutProvider.jsx` writes `fadeTextOpacity` each frame (unchanged logic; the F-bars still fade out fast while the text fades in slowly).
  - The round buttons (play, playlists, admin, identity) stayed in the tab stack. They were moved up for a while mid-session, then put back.
- `frontend/src/components/BrandScaleTool.jsx` (new) + a few lines in Strip.jsx + a plugin in `frontend/vite.config.js` — a TEMPORARY sizing tool. Open the app with `?brandtool`: sliders for CHEWING and THE CEILING separately, drag the wordmark to move it, "Save for Claude" writes `frontend/brand-scale.json` (needs the dev server restarted to pick up the vite plugin), "Copy values" copies the JSON.
  - Values set with the tool are kept in the browser's localStorage (`lnv_brand_scale`) and WIN over the defaults above.
